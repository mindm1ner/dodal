# 도달점

초등 교육과정 성취기준 검색 도구. 2022 개정부터 제7차까지 다섯 교육과정 4,248건.

**https://mindm1ner.github.io/dodal/**

- 낱말·성취기준 코드·영역명으로 즉시 검색 (띄어쓰기 무시, 초성 검색)
- 두 성취기준을 나란히 놓고 낱말 차이 확인
- 다른 교육과정의 비슷한 성취기준 추천
- 2009·2007·제7차 원문에는 성취기준 코드가 없어 번호는 도달점이 붙였습니다
  (화면에 "번호는 도달점이 붙임"으로 표시. 제7차 사회의 심화 과정도 표시)

수집·생성 코드는 개인 저장소에 있습니다. 이 저장소는 배포용 산출물만 담습니다.
성취기준 원문 출처: 국가교육과정정보센터(NCIC).
